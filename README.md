# 拾字

适用于 macOS 13 及以上的截屏取字工具。使用 Apple Vision 在本机识别截图或图片中的中英文，保留识别出的换行。截图和文字只在当前会话中使用。

## 使用

1. 双击 `build/拾字.app`。也可以先拖到「应用程序」再打开。
2. 点击「截屏取字」，或在其他应用中按 **⌘⇧2**。在目标屏幕上拖动框选区域，松开后自动识别。按 **Esc** 取消。
3. 在结果的文字区域拖选需要的部分，按 **⌘C**，再切换到目标应用按 **⌘V**。也可以点击复制按钮直接复制全文或选区。

应用运行期间，菜单栏的取字图标可以启动截图或重新打开结果窗口。关闭窗口后仍可用快捷键截图，按 **⌘Q** 退出应用。如果快捷键已被占用，使用菜单栏的「截屏取字」即可。

第一次截图时，根据系统提示在「系统设置 → 隐私与安全性 → 录屏与系统录音」（早期系统称「屏幕录制」）允许拾字录屏。系统如提示重新打开应用，照提示操作即可。也可以使用窗口中的图片导入按钮或 **⌘O** 打开现有图片，无需录屏权限。

## 从源码构建

在有 Swift 5.9 或更新版本及 macOS 14 或更新 SDK 的 Mac 上运行以下命令。脚本会生成同时包含 Apple Silicon 和 Intel 架构的本地签名应用。

```sh
./Scripts/build.sh
open build/拾字.app
```

构建与使用均无需安装第三方依赖。
